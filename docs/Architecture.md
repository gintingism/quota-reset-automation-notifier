# Architecture

Quota Reset Automation Notifier runs on Cloudflare Workers (`src/index.js`) with a 5-minute Cron Trigger (`*/5 * * * *`) and a `QUOTA_KV` namespace for state.

## Components

- **`src/oauth.js`**: Resolves the primary Antigravity account plus any optional entries from `ANTIGRAVITY_ACCOUNTS`, exchanges each refresh token at `oauth2.googleapis.com/token`, and caches tokens per account in `QUOTA_KV` (`oauth:access_token` / `oauth:access_token:<id>`) with a 5-minute refresh buffer. Raises `AuthRevokedError` on `invalid_grant`.
- **`src/cloudcode.js`**:
  - Calls `POST /v1internal:loadCodeAssist` on `daily-cloudcode-pa.googleapis.com` to resolve `cloudaicompanionProject` and tier per account (`cloudcode:project_info` / `cloudcode:project_info:<id>` cached for 24h).
  - Calls `POST /v1internal:fetchAvailableModels` and `POST /v1internal:retrieveUserQuotaSummary` using `User-Agent: antigravity/hub/2.24.0 linux/x64` so active quota pools (`Gemini Models` and `Claude and GPT models`, including `Gemini 4 Carbon`, `Neon`, and `Hydrogen`) are returned; ignores removed Argon pools, resolves nested `quotaInfo` buckets, and synthesizes missing Gemini `5H` windows from `fetchAvailableModels`.
  - Sends `"1+1="` to `POST /v1internal:streamGenerateContent?alt=sse` (`Accept: text/event-stream`, `maxOutputTokens: 1`, `stopSequences: ['\n']`, `thinkingBudget: 0`, no `systemInstruction` by default with 1-token `.` fallback on `400`, `-low`/`flash-lite` preference with live `Medium` fallback, strict `daily-cloudcode-pa` host isolation on 404) when Auto-Wake triggers.
- **`src/wake_engine.js`**: Evaluates each pool (`Gemini Models`, `Claude and GPT models`) with 4 guards (`remaining_fraction >= 1.0`, 2-minute safety margin after `lastTriggeredResetAt`, 10-minute cooldown, and new `reset_time_iso` or 5-hour `IDLE_CYCLE_COOLDOWN_MS` when `reset_time_iso` is `null` on idle 100% pools) plus `WAKE_TIME_WINDOW` and weekly quota > 0%.
- **`src/calendar.js`**: Upserts weekly reset schedules (Antigravity Weekly, Gemini Web Weekly, and optional Copilot Monthly; 5-hour windows excluded) to Google Calendar API v3 and Google Tasks API v1 using `GCAL_*` OAuth secrets, with settings in `QUOTA_KV` (`calendar:settings`) and cycle deduplication (`calendar:sync_state`).
- **`src/history.js`**: Stores a rolling 24-hour ring buffer in `QUOTA_KV` (`history:quota`, up to 96 points sampled every 15 minutes or on >=5% quota changes), computes per-series burn rate (`%/hour`), and renders inline SVG sparklines.
- **`src/index.js`**: Orchestrates cron and API ticks across single or multiple Antigravity accounts, Copilot, history recording, and Google Calendar/Tasks sync; serves `/api/quota/latest`, `/api/quota/history`, `/api/quota/sync`, `/api/automation/tick`, `/api/automation/wake`, `/api/settings/calendar`, and `/api/calendar/sync`.
- **`src/copilot.js`**: Calls `GET https://api.github.com/copilot_internal/user` when `GITHUB_TOKEN` is set to read monthly AI credits (`credits_used`, `credits_remaining`, `entitlement`, `quota_reset_date_utc`).
- **`src/notifier.js`**: Sends Telegram (`api.telegram.org/bot.../sendMessage`) and Discord webhook messages with retry/backoff and persistent deduplication in `QUOTA_KV` (`notify:dedup_state`).
- **`src/dashboard.js`**: Renders the HTML status dashboard (`GET /`) with 24-hour burn-rate sparklines, a collapsible Google Calendar & Tasks settings panel, multi-account Antigravity cards, wake decision badges, filterable model table, live 1-second countdowns, and an `ID | EN` language switcher (`localStorage` key `qra_lang`).
- **`src/gemini_rpc.js`**: Pure parsers for Gemini's `batchexecute` RPC (`jSf9Qc` quota windows and `otAQ7b` policy tier) and `GEMINI_WEB_GRAPHQL` (`UsagePageQuery`), plus `computeBurnRateForecast()` for pace/depletion estimation.
- **`extension/`**: Chrome Manifest V3 extension (`v1.4.0`) that queries Gemini's `batchexecute` RPC (`jSf9Qc` and `otAQ7b`) directly from the service worker, falls back to `GEMINI_WEB_GRAPHQL` (`UsagePageQuery`), and only uses a resource-filtered `offscreen` iframe DOM scraper if both fail. Syncs `gemini_web` snapshots to `POST /api/quota/sync` and renders a popup with `Gemini Web`, multi-account `Antigravity` (5h + Weekly + Wake button), `GitHub Copilot`, connection testing, and `Google Calendar & Tasks` settings.
