# Architecture

Quota Reset Automation Notifier runs on Cloudflare Workers (`src/index.js`) with a 5-minute Cron Trigger (`*/5 * * * *`) and a `QUOTA_KV` namespace for state.

## Components

- **`src/oauth.js`**: Exchanges `ANTIGRAVITY_REFRESH_TOKEN` for a Google OAuth2 `access_token` at `oauth2.googleapis.com/token` and caches it in `QUOTA_KV` (`oauth:access_token`) with a 5-minute refresh buffer. Raises `AuthRevokedError` on `invalid_grant`.
- **`src/cloudcode.js`**:
  - Calls `POST /v1internal:loadCodeAssist` on `daily-cloudcode-pa.googleapis.com` to resolve `cloudaicompanionProject` and tier (`cloudcode:project_info` cached for 24h).
  - Calls `POST /v1internal:fetchAvailableModels` and `POST /v1internal:retrieveUserQuotaSummary` using `User-Agent: antigravity/hub/2.24.0 linux/x64` so all quota pools (`Gemini Models`, `Claude and GPT models`, and `Gemini 4 Argon`) are returned; resolves nested `quotaInfo` buckets, proto3 omitted zero fractions, and synthesizes missing Gemini `5H` windows from `fetchAvailableModels`.
  - Sends `"1+1="` to `POST /v1internal:streamGenerateContent?alt=sse` (`Accept: text/event-stream`, `maxOutputTokens: 1`, `stopSequences: ['\n']`, `thinkingBudget: 0`, no `systemInstruction` by default with 1-token `.` fallback on `400`, `-low`/`flash-lite` preference with live `Medium` fallback, strict `daily-cloudcode-pa` host isolation on 404) when Auto-Wake triggers.
- **`src/wake_engine.js`**: Evaluates each `5H` pool (`Gemini Models`, `Claude and GPT models`) with 4 guards (`remaining_fraction >= 1.0`, 2-minute safety margin after `lastTriggeredResetAt`, 10-minute cooldown, and new `reset_time_iso` or 5-hour `IDLE_CYCLE_COOLDOWN_MS` when `reset_time_iso` is `null` on idle 100% pools) plus `WAKE_TIME_WINDOW` and weekly quota > 0%.
- **`src/index.js`**: Orchestrates cron/API ticks, ranks pool wake candidates (`-low`/`flash-lite` first, then live models such as `Gemini 3.8 Flash` / `Gemini 4 Hydrogen`), anchors idle wakes to `now + 5h`, and isolates non-limit `wake_failed` errors per pool without aborting sibling pools.
- **`src/copilot.js`**: Calls `GET https://api.github.com/copilot_internal/user` when `GITHUB_TOKEN` is set to read monthly AI credits (`credits_used`, `credits_remaining`, `entitlement`, `quota_reset_date_utc`).
- **`src/notifier.js`**: Sends Telegram (`api.telegram.org/bot.../sendMessage`) and Discord webhook messages with retry/backoff and persistent deduplication in `QUOTA_KV` (`notify:dedup_state`).
- **`src/dashboard.js`**: Renders the HTML status dashboard (`GET /`) grouped by provider (`Antigravity` with nested pool cards, wake decision badges, and filterable model table, `GitHub Copilot`, and `Google Gemini Web` with burn-rate pace), live 1-second reset & cron countdowns, inline SVG brand marks, token breakdown (`in`/`think`/`out`), and an `ID | EN` language switcher (`localStorage` key `qra_lang`).
- **`src/gemini_rpc.js`**: Pure parsers for Gemini's `batchexecute` RPC (`jSf9Qc` quota windows and `otAQ7b` policy tier) and `GEMINI_WEB_GRAPHQL` (`UsagePageQuery`), plus `computeBurnRateForecast()` for pace/depletion estimation.
- **`extension/`**: Chrome Manifest V3 extension that queries Gemini's `batchexecute` RPC (`jSf9Qc` and `otAQ7b`) directly from the service worker (zero iframe overhead, <2 MB RAM, exact Unix reset timestamps, and plan tier detection), falls back to `GEMINI_WEB_GRAPHQL` (`UsagePageQuery`), and only uses a resource-filtered `offscreen` iframe DOM scraper if both fail. Syncs `gemini_web` snapshots to `POST /api/quota/sync` and renders a popup with separate `Gemini Web`, `Antigravity`, and `GitHub Copilot` cards, burn-rate forecast, bundled `lucide` icons (`extension/vendor/lucide.min.js`), and an `ID | EN` language switcher (`chrome.storage.local` key `uiLang`).
